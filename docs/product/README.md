# Kontekst produktu

Ten katalog jest pusty w starterze. Aplikacja budowana na starterze opisuje tu swoją domenę, żeby ludzie i agenci AI mieli ją w jednym miejscu:

- `prd.md` – wymagania produktu,
- `glossary.md` – słownik pojęć domeny,
- dodatkowe ADR-y aplikacji trafiają do `docs/decisions/`.

Własne skille aplikacji dodawaj w `.claude/skills/` z prefiksem aplikacji (np. `shop-add-order-status`), bez edytowania skilli startera (PRD, AI-10).
